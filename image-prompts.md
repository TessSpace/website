# AI image prompts

These prompts are written to work in both ChatGPT image generation and Gemini image generation. Use `21:9` for the strongest full-screen desktop result, or `16:9` if the model handles that better. In every case, ask for:

- photorealistic
- no text
- no logos
- no watermark
- no UI
- left-side negative space for website copy
- restrained defense-grade color palette
